# S. 壁 — обновление платформы

## Что добавлено
- Переключение светлой/тёмной темы с сохранением выбора в браузере.
- Загрузка обложек JPG/PNG/WEBP/GIF до 8 МБ из панели владельца.
- Счётчики уникальных просмотров произведений (один просмотр на браузер/аккаунт).
- Профиль пользователя: подписчики, подписки, число работ и суммарные прочтения.
- Подписка на автора, редактирование описания профиля.
- Избранное/библиотека.
- Безопасное расширение существующей SQLite-схемы без удаления текущих новелл и глав.

## Важно перед запуском
1. Сделайте резервную копию базы данных SQLite.
2. Замените `app.py` и `templates/index.html` в репозитории, а также проверьте `requirements.txt`.
3. В Render → Environment задайте:
   - `SECRET_KEY` — длинная случайная строка.
   - `OWNER_LOGIN` — логин владельца.
   - `OWNER_PASSWORD` — новый пароль владельца.
   - `READER_LOGIN` — SantasWall2011.
   - `READER_PASSWORD` — пароль, который вы хотите назначить обычному аккаунту.
   - `COOKIE_SECURE` — 1.
4. Не добавляйте пароли в GitHub и не помещайте их в HTML или app.py.
5. Если в Render используется SQLite без Persistent Disk, база и загруженные обложки могут пропасть при пересоздании экземпляра. Для постоянного хранения подключите Persistent Disk и задайте `DATABASE_PATH` на путь внутри диска; папку `static/uploads` также нужно хранить на постоянном диске или перенести в объектное хранилище.

## Сохранность данных
Миграции добавляют новые столбцы и таблицы. Код не очищает таблицы `works`, `chapters`, `comments` и `users`. Но перед заменой обязательно сделайте резервную копию.
